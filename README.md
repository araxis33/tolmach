# Толмач

Переводчик RU⇄EN для Chrome на Claude. Выделяешь текст на любом сайте — получаешь
перевод, который читается как написанный человеком, а не выданный машиной.

Толмач — старое русское слово для живого переводчика, который переводит смысл,
а не подставляет слова из словаря. Отсюда и название.

## Что он умеет

- **Выделил — перевёл.** Рядом с выделением всплывает кнопка. Или `Alt+T`.
  Перевод печатается на глазах, а не появляется через три секунды молчания.
- **Второй вариант.** К каждому переводу — альтернативная формулировка,
  если она вообще осмысленно отличается.
- **Четыре тона.** Естественно, дословно, для твита, официально. Переключаются
  прямо в карточке — текст перегоняется заново.
- **Вся страница.** `Alt+P` переводит страницу сверху вниз, кусками, на глазах.
  Второе нажатие возвращает оригинал.
- **Своё окно.** Клик по иконке — поле для своего текста. Если на странице
  что-то выделено, оно подставится само.
- **Личный словарь.** Слова, которые надо переводить именно так и не иначе.

## Чего он не делает

Не трогает тикеры (`$ETH`), хэндлы (`@vitalik`), ссылки, адреса кошельков,
код и названия протоколов. Они остаются как есть — в обе стороны.

## Установка

1. Открой `chrome://extensions`
2. Включи **Режим разработчика** (переключатель справа сверху)
3. **Загрузить распакованное расширение** → выбери эту папку
4. Откроется страница настроек — вставь ключ Anthropic и нажми **Проверить**

Ключ берётся на [console.anthropic.com](https://console.anthropic.com/settings/keys).
Счёт надо пополнить — Anthropic не даёт бесплатной квоты.

## Сколько стоит

Платишь Anthropic по факту, за токены. По ценам Opus 5 ($5 за млн входных,
$25 за млн выходных) перевод абзаца — доли цента; активный день чтения
англоязычных лент упирается в единицы центов. Целая страница дороже
одного выделения — там текста в разы больше.

В настройках можно переключить модель на Sonnet 5 или Haiku 4.5, если хочется
быстрее и дешевле.

## Где лежит ключ

В `chrome.storage.local` этого браузера. Читает его только service worker —
он и ходит в Anthropic. На страницы, которые ты открываешь, ключ не попадает
никогда: скрипт страницы умеет только попросить перевод и получить текст.
Проверяется автоматически, см. `check.mjs`.

## Разработка

```bash
node test-engine.mjs   # чистые функции: определение языка, разбор ответа, пакеты
node check.mjs         # манифест, файлы, синтаксис, права, утечка ключа
python make-icons.py   # перерисовать иконки
```

Как устроено:

| Файл | За что отвечает |
|---|---|
| `engine.js` | Промпты, запросы к Claude, разбор потока. Единственное место с ключом. |
| `background.js` | Service worker: меню, горячие клавиши, раздача переводов по портам. |
| `content.js` | Всё, что видно на странице. Живёт в shadow root, стилями не пересекается. |
| `popup.js` | Окно расширения для своего текста. |
| `options.js` | Настройки и живая проверка ключа. |

Перевод идёт потоком: service worker читает SSE от Anthropic и шлёт куски
в карточку через порт. Закрыл карточку — порт рвётся, запрос отменяется,
недогенерированное не оплачивается.
